## Project Overview

This is a Python 3.11.4 project initialized with PyCharm, currently in early development. The project name "chat-robot" suggests an intended chatbot/conversational AI application, but implementation has not yet begun.

## Development Commands

### Running the Application
```bash
python main.py
```

Or using the virtual environment:
```bash
.venv\Scripts\python.exe main.py
```

### Virtual Environment
- Virtual environment located at `.venv/`
- Activated scripts are in `.venv\Scripts\` (Windows)

### Code Formatting
- Black formatter is configured in PyCharm settings
- No explicit formatting command is configured in scripts

## Project Structure

- `main.py` - Main entry point (currently contains only PyCharm template code)
- `.venv/` - Python virtual environment (excluded from source)
- `.idea/` - PyCharm IDE configuration

## Notes
